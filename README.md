# 細胞のつくりあて（saibo-tsukuri）

顕微鏡で見たことやつくりの説明（染色液で赤く染まる・緑色の粒・厚くてじょうぶなしきり など）を読んで、細胞のつくり（核・細胞膜・細胞壁・葉緑体・液胞）を当てる1日5問の学習ゲーム。正解したら「どんなはたらき？」（細胞のしきりになる・光合成を行う・細胞の中で物質をもつ・ためる）も選ぶ。中学2年理科「生物と細胞」。

遊ぶ: <https://satou-aaaaa.github.io/saibo-tsukuri/>

- 中身は大阪府教育委員会・千葉県教育委員会の理科プリント（解答）、大阪府教育センターの指導案、長野県総合教育センターのクリア問題、岩手県の教材、神戸大学の実験資料で確かめたことだけです。
- ミトコンドリアと細胞質は扱いません。液胞は、中学の資料にならって植物の細胞だけに見られるものとしています。このゲームは教科書の代わりではありません。くわしくは教科書で確かめてください。
